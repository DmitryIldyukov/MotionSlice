# MotionSlice

> Превращай длинный контент в короткие, цепляющие форматы — с помощью AI.

MotionSlice — платформа с набором независимых AI-сервисов для обработки контента. Каждый сервис решает одну задачу: берёт что-то большое и превращает это в то, что можно сразу использовать.

---

## Сервисы

### ArticleSlice *(в разработке)*
Суммаризация статей и текстов.  
Закидываешь статью — получаешь краткое описание с главными событиями и готовый пост для соцсетей.

### VideoSlice *(на этапе идеи)*
Нарезка длинных видео и стримов на короткие клипы.  
Загружаешь стрим — платформа сама находит интересные моменты и нарезает их на фрагменты с описаниями.
